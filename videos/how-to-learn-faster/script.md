# The rundown on how to learn anything faster

Idea: Learning slowly is usually learning passively. Pick one tiny skill, practise it right away, get feedback.

Target: about 25 seconds, about 77 spoken words. Read it at a normal pace, no rush.
Record it, drop the file in this folder (any name, .m4a is fine). Not made yet: the scenes (`shots.json`)
still need to be written before running `python3 tools/make.py how-to-learn-faster`.

## Hook options (the first is used)
1. You're not slow. You're learning the hard way.
2. Why does learning anything take forever?
3. Learn anything faster with this.

## Script
You're not slow. You're just learning the hard way.

Most people think they need hours of study first.

But watching someone do it isn't the same as doing it.

Step one. Pick one tiny piece. Not the whole skill, just one part.

Step two. Practice it right away. Even badly.

Step three. Get feedback. From a person, a recording, anything honest.

Repeat that loop, and you improve a lot faster.

That's the rundown. Small piece, practice, feedback.
